# 👋 START HERE - Amara's Portfolio

## ⚡ Quick Start (3 Steps)

### 1. Install
```bash
npm install
```

### 2. Add Your Files
- Add 4 project images to `/public/projects/`
- Add your CV to `/public/Amara_Kamara_CV.pdf`

### 3. Run
```bash
npm run dev
```
Open → http://localhost:3000
